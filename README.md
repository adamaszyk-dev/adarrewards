# ADAR NOW Landing Page

Statyczna strona prezentacyjna promująca natychmiastowe płatności ADAR NOW dla przewoźników.

## Podgląd

Otwórz lokalnie plik `index.html` w przeglądarce lub uruchom dowolny serwer statyczny:

```bash
python -m http.server 8000
```

## Zawartość

- `index.html` – pełna struktura strony z dwunastoma sekcjami narracyjnymi.
- `styles.css` – styl w kolorystyce ADAR (czerń, neonowy błękit i czerwień) oraz hierarchia typografii.
- `script.js` – animacja licznika 5-minutowego i płynne obracanie opinii.
